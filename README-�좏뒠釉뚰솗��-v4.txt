CJ스튜디오 관리자 유튜브 음원 확인 v4

추가 기능
1. 신청곡 승인 완료 후 유튜브 음원 확인 여부 안내
2. 각 일반 신청곡에 ▶ 유튜브 음원 확인 버튼 표시
3. youtubeUrl, youtubeLink, url 필드에 유튜브 주소가 있으면 해당 영상 바로 열기
4. 저장된 주소가 없으면 곡명 + 가수명으로 유튜브 검색
5. 가사 키워드 신청에는 유튜브 버튼을 표시하지 않음

적용 방법
- admin-app.js와 admin-style.css를 기존 GitHub 저장소 파일에 덮어쓰기
- admin.html은 기존 v3와 동일하지만 함께 포함됨
- firebase-config.js는 기존 저장소 파일을 그대로 사용
