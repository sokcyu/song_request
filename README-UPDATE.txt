CJ스튜디오 음원 신청 프로그램 - 회원 승인 음악 알림 업데이트

추가 기능
1. 관리자 > 회원 승인 관리에서 "승인 + 음악 제목" 클릭
2. 음악 제목 입력
3. 회원 status=approved 와 approvalSongTitle/approvalNotice가 Firestore members 문서에 저장
4. 승인 회원이 이용자 페이지에 로그인하면 "회원 승인 알림" 카드에서 음악 제목 확인
5. 확인 버튼을 누르면 읽음 상태 저장

중요: 이 ZIP에는 "웹 이용자 페이지 실시간 알림" 기능이 구현되어 있습니다.
실제 카카오톡/카카오 알림톡 자동 발송은 별도 서버(Firebase Functions 등)와 카카오 비즈메시지 공급자/API 인증 정보가 필요하므로 정적 GitHub Pages 파일만으로는 포함할 수 없습니다.

배포: 기존 GitHub Pages 저장소 파일을 이 폴더 파일로 교체 후 커밋/푸시하세요.
